## Ejemplos

### Futbol stats
Consiste en la base de datos de FIFA 2024 MEN, donde se dispone de un puntaje 0 a 100 de la performance de cada jugador en distintos factores futbolísticos, así como también datos referidos a su valor económico de mercado, su edad, altura y peso. 

### Genómica cáncer de mama
STRING (Search Tool for the Retrieval of Interacting Genes/Proteins) es una base de datos y plataforma que integra información sobre interacciones proteína-proteína, tanto físicas como funcionales. Se basa en diversas fuentes, fundamentalmente: Experimentos de laboratorio (ej. cristalografía, ensayos de doble híbrido), Minería de textos de publicaciones científicas.
The cancer genome atlas es un proyecto de investigación colaborativa. Su objetivo fue crear un atlas molecular completo y sistemático de los cambios genómicos que ocurren en múltiples tipos de cáncer, mediante la aplicación de tecnologías genómicas de alto rendimiento. En esta exploración trabajamos solo con la capa de datos de Transcriptómica (RNA-Seq) correspondiente a la cohorte de Carcinoma de Mama (TCGA-BRCA). Se analizaron los niveles de expresión génica (mRNA) de muestras clasificadas como 'Tumor Sólido Primario'
